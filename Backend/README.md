# Flask Backend – JWT Authentication with MongoDB

Backend aplikacji stworzony w **Flasku** z obsługą **rejestracji, logowania, JWT autoryzacji** oraz połączeniem z bazą **MongoDB**.

---

## Pobieramy mongodb 8.2.1

https://www.mongodb.com/try/download/community

##

Tworzymy na dysku **c** pliki **c:\Data\db**

## Uruchomianie mongo

## Tworzymy ENV

### Dla windows:

```
python -m venv venv
venv\Scripts\activate
```

### Dla linux/mac:

```
python3 -m venv venv
source venv/bin/activate
```

## Instalujemy pakiety

```
pip install -r requirements.txt

```

## Uruchomienie projektu

```
python -m app
```
